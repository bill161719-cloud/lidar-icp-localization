# 需求与验收标准

项目：面向激光 SLAM 的 C++ 点云配准与相对位姿估计系统；仓库 lidar-icp-localization。
面向有 Python/GIS 基础的本科生，要求可解释、可编译、可复现。使用 C++17、PCL、Eigen、CMake、Git。

| 编号 | 功能 | 验收证据 |
|---|---|---|
| R01 | PCD 读取 | 合法文件成功；缺失、空文件、无效点有明确错误 |
| R02 | 预处理与可视化 | 按 XYZ 有限性剔除 NaN/Inf，不依赖 is_dense；体素减少点数；原始/处理后图片 |
| R03 | 两帧 PCL ICP | 输入 source/target/初值，输出最终 T_target_source、收敛状态、迭代配置与耗时 |
| R04 | Eigen 位姿分析 | 4×4 矩阵、旋转矩阵/四元数、平移，检查 SO(3) 和齐次末行 |
| R05 | 误差 | fitness、独立最近邻 RMSE/内点数/比例，明确门限及单位 |
| R06 | 人工真值 | 固定种子非对称三维点集，已知变换；干净近初值场景平移误差 <0.01 m、旋转误差 <0.1°；噪声/离群点单独报告 |
| R07 | 少量真实道路帧 | 数据来源/许可/帧 ID、转换命令、重叠率/初值、失败分析；无真值不得宣称绝对定位精度 |
| R08 | 图像与实验 | 同一视角配准前后图片，CSV 指标，配置、版本、命令和原始日志可追溯 |
| R09 | 交付 | 全新目录构建与 CTest；中文 README、局限、许可证与第三方说明、GitHub 操作步骤 |

第一版不含完整 SLAM、FAST-LIO、IMU/IEKF、ROS、GPU、自研完整 ICP 求解器或复杂 GUI。
初始化只验收工具链探测、接口、目录、最小 C++17 构建、bootstrap 测试和基础提交。
完整功能尚未实现时不得对外宣称已完成 R01–R09。
